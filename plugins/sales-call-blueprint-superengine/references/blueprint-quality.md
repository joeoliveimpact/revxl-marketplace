# Blueprint Quality Checklist

**Purpose:** Final gate before delivering any blueprint. Every item is pass/fail. If any fail, fix before handing to the closer.

## Specificity & Voice
- [ ] Every section references something the prospect *actually said* — nothing generic
- [ ] The prospect's exact words/phrases are quoted and mirrored (not paraphrased into corporate-speak)
- [ ] Communication style is identified and the scripts match that energy
- [ ] The thread/file is named after the prospect

## Intel Integrity (no fabrication)
- [ ] No invented pain points, numbers, or emotional states — gaps are marked `[CONFIRM LIVE]` / `[NOT IN DMs]`
- [ ] Closing Probability has explicit reasoning
- [ ] If triage notes were provided, confirmed data is integrated (deepened, not re-asked)
- [ ] If DMs were thin, the gaps were converted into priority discovery questions

## Structure & Method
- [ ] Strategy blueprint follows RFPDP (Rapport → Frame → Pain → Discovery → Pitch)
- [ ] Discovery topics are RANKED for this prospect, not left in template order
- [ ] Partner/spouse variable is handled in discovery, not at the close (if applicable)
- [ ] Pitch has a temperature check before delivery/price
- [ ] Price drop is structured and ends with "stop talking" (you supply the figure — pricing isn't stored)

## Triage-Specific (triage blueprints only)
- [ ] NO specific pricing discussed — pricing deflection script included
- [ ] Clear in/out decision criteria present
- [ ] Job is to qualify and book the strategy call, not to pitch

## Output Hygiene
- [ ] Config variables ({{BRAND_NAME}}, {{CLOSER_NAME}}, etc.) are resolved, not left as raw tokens (pricing is never a config value — the user supplies it live)
- [ ] Risks/landmines are explicitly flagged
- [ ] "If you remember only 3 things" is present and sharp
- [ ] Requested output mode(s) delivered (Pre-Call Prep / Call-Time Blueprint / both); if both, they're consistent
- [ ] Blueprint delivered to the configured {{OUTPUT_DESTINATION}} and the exact location/link confirmed back to the user
