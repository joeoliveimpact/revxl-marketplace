# Post-Call Notes Template (Triage)

Filled immediately after a triage call to hand confirmed intel to {{CLOSER_NAME}} for the strategy call. Output file naming: `[Prospect Full Name] - TRIAGE NOTES - [MM.DD.YY].md`.

> The triage call's whole purpose is to feed the strategy call. This template captures what was confirmed so the strategy blueprint can deepen — not re-ask — those points. `[square]` = filled from the call.

```template
# [PROSPECT NAME] — TRIAGE NOTES · [MM.DD.YY] · setter: [caller]

**Decision:** [QUALIFIED / DISQUALIFIED / BORDERLINE]
**Monthly Revenue:** [confirmed number]
**Bottleneck:** [their words]
**90-Day Goal:** [their words]
**Urgency Source:** [what's driving the timing]
**Trust Level:** [how much they know about {{BRAND_NAME}}/{{CLOSER_NAME}}]
**Financial Flags:** [investment-capacity concerns]
**Logistical Flags:** [location, currency, partner, timezone]
**Coachability Signal:** [did they track numbers / take action / follow through?]
**Key Language to Mirror:** [2-3 exact phrases for the strategy call]
**Strategy Call Booked?:** [YES/NO + date/time]
**Additional Notes:** [anything else {{CLOSER_NAME}} needs to know]
```

## Field Documentation
| Field | Source | Notes |
|-------|--------|-------|
| Decision | The in/out qualification call | Drives whether a strategy call is booked at all |
| Monthly Revenue | Operational snapshot | Confirmed absolute number, not a range |
| Key Language to Mirror | Prospect's verbatim phrases | Feeds the strategy blueprint's mirroring |
| `{{CLOSER_NAME}}` | references/business-config.md | Substituted at render |

## Section Specifications
- **Fill immediately:** Memory decays fast — capture before the next call.
- **Confirmed only:** This is the intel the strategy blueprint treats as fact. Don't log guesses here; if unsure, mark `[unconfirmed]`.
- **Hand-off ready:** Written FOR the closer — terse, scannable, decision-first.
