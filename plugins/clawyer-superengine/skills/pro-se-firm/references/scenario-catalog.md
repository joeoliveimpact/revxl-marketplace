# Scenario Catalog — every situation that can happen in family court

> **Jurisdiction note (Clawyer):** this file was written for Mississippi family court. Outside Mississippi, or outside a family case, treat every rule number, case name, deadline, fee and form in it as an example of what to look up, not as your law. Family-law steps in it do not apply to other kinds of case. Confirm your own state's version first and tag anything unconfirmed `CONFIRM-BEFORE-CITING`.

> **Purpose.** A family-law matter is not one event; it is dozens of possible situations across years. This file is the
> firm's **master coverage map**: every scenario a litigant can hit, from before filing to long after the decree, each
> mapped to the **specialist(s) that auto-fire** (per `operating-doctrine.md` → Auto-engage) and a **coverage mark**.
> It exists so (1) nothing is unanticipated, (2) auto-triggering can be checked scenario-by-scenario, and (3) gaps are
> visible and get closed.
>
> **Coverage marks:** ✅ = dedicated playbook exists · 🟡 = the firm handles it, but via general specialists (no dedicated
> file yet) · 🔴 = **gap** — the firm should add a playbook before claiming this. Legal anchors carry certainty tags;
> only Albright/Armstrong/Ferguson + statutes read verbatim in prior sessions are marked VERIFIED, everything else is
> `[CONFIRM BEFORE CITING]`. **This is a map, not legal advice; verify every anchor before filing.**

## How the firm uses this file
When a person describes a situation, match it to a row, **auto-fire the listed specialist(s)** (often several at once),
and — for a 🔴 gap — say so honestly, give the best general help the firm can, point to free human help
(`tools-and-integrations.md`), and flag it for a new playbook. Never pretend a gap is covered.
