# focus-group-superengine

Test any marketing artifact against a synthetic focus group before you ship it.

## What it does
You bring a name line, bio, hook, thumbnail, email, offer, or ad... it builds a reusable audience of fake-but-realistic buyers for YOUR niche, runs them as an isolated panel (each panelist reacts alone, so nobody copies the loudest voice), and returns a verdict: which option wins on attention, which wins on convert, the behavioral funnel, the top objections, and verbatim quotes. A/B testing without burning a real launch on the loser.

With **Teach Mode** on (default), it explains the *why* behind each read in plain English as it goes... so you learn to read your own audience, not just get the verdict. Say "teach mode off" anytime.

## Skills
| Skill | What it does |
|---|---|
| `/focus-group-setup` | Builds a persona pack from your real assets (site, socials, docs) + a short Q&A. One pack per brand; reusable for every test. |
| `/focus-group-run` | Tests an artifact against the pack. Pick depth (fast / deep / hyperreal) and temperature (cold strangers / warm followers / hybrid), get a dual-axis verdict + results doc. |

Ships with a generic coach/SMB example pack so it works out of the box... build your own pack for real results.

## Honest limits
- Verdicts are **directional** (A beats B), not metric predictions. Confirm big calls with one real signal (a Story poll, real comments).
- Deep runs use multiple AI calls (panel × options). The skill always estimates the cost and asks before any heavy run.

## What's a skill?
A set of instructions Claude loads automatically when you need it. Install once, then Claude just knows how to do the thing... no prompts to memorize.
