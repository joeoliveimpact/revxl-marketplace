## Grades (travel with every fact)

- **LOCKED** — externally confirmed. Build on it, state it plainly.
- **DIRECTIONAL** — direction right, numbers are practitioner lore. State the
  direction; never quote the specifics as fact.
- **CORRECTED** — the old advice was wrong; the correction is what locks.
- **FLAGGED** — unresolved; treat as unknown, say so.

## Epistemic rules (govern everything)

1. **Strip every unattributed stat.** No percentage enters generated copy,

## The rules skills build on

### Targeting + structure (LOCKED direction)
- Broad targeting (location + age floor + language) is the acquisition
  default. **Creative is the targeting** — Andromeda retrieves ads by
  creative signals.
- Consolidate: ONE campaign, ONE ad set at Stage 1; no separate testing/
  retargeting campaigns below ~$300/day. Advantage+ sequences users inside
  one campaign.
- Automated bidding (highest volume) baseline; manual/cost caps are $300+/day
  levers.
- Raise budgets **in place**, gradually (~10–20% per 48–72h — DIRECTIONAL
  numbers, LOCKED principle: never reset learning, never duplicate-to-scale).

### Signals (LOCKED)
- Pixel + CAPI dual-tracking with `event_id` dedup, at ALL spend levels (the
  "$5k/mo threshold" is obsolete). One-click CAPI is real (Apr 2026).
- AI-assisted Pixel: real, auto-enables, **opt-out** — review on every
  account touched.
- Qualified events over raw leads: fire the money event on YOUR
  qualification bar. Expect CPL up, cost-per-qualified-lead down — that
  trade is the point.
- EMQ: maximize on money events, direction only — never chase specific
  decimals (vendor lore).
- AEM prioritization: obsolete (iOS14-era). Don't teach it.

### Creative (the biggest shift)
- Distinct concepts beat volume: 3–5 at Stage 1, ~8–20 at scale
  (DIRECTIONAL counts, LOCKED principle). Near-duplicates get bundled and
  compete as one ad.
- Micro-variants live ONLY in Meta's native Creative-Testing Tool (LOCKED:
  real, ≤5 variants, Highest-Volume-only caveat). Everything else tests
  **dimensional swings**.
- Coach-scale statistics: ~90% confidence, 7–10 days or ~100 conversions;
  48–72h fast-kill for clear duds. 95%-confidence tables are six-figure-spend
  tools.
- Formats: 4:5 feed default (LOCKED, official); 9:16 for Reels/Stories with
  safe zones **top 14% / bottom 35% / sides 6%** (LOCKED — the pack's 10/10
  rule is wrong). Copy limits: 125 visible primary / 40 headline (LOCKED).
- Video: bipolar lengths — 15–30s direct AND 90–120s+ VSL (DIRECTIONAL).
- Text overlays: the 20% rule is retired; overlays are READ by the machine —
  make them meaningful, keep them tight. "Dense text now favored" is FALSE.

### Copy
- Formulas hold (PAS/BAB/social-proof/DR); ALL their attached conversion
  stats are stripped ("+22%", "+17%" = laundered).
- Copy doubles as targeting signal — mine real client language.
- Default CTA buttons + strong in-copy CTA; button micro-testing is dead
  weight.
- 5-slot copy variants live inside ONE ad, never as separate ads.

### Compliance (every entry was a corpus failure — LIVE CHECK ALWAYS)
- **Financial Products & Services** is a 5th Special Ad Category (Oct 2024,
  enforced Jan 2025). Financial coaching CAN trigger it; "coaching never
  triggers SAC" is wrong. Check per-offer.
- AI-creative labeling: no global mandatory toggle; political/SIEP disclosure
  since 2024; **C2PA auto-labeling from Jun 1 2026**. Synthetic-UGC: expect
  labels; the real cost is trust + policy drift. Re-check before scaling
  AI-avatar creative.
- Health-data pixel rules: **FLAGGED** — verify before health-coaching pixel
  events.

### Measurement
- Optimize on primary metrics only: spend, results, cost/result, blended
  ROAS. CTR/CPM/frequency/hook-rate are storytelling metrics (see
  `metrics.md`).
- Backend over dashboard: blended MER + nCAC at scale; Meta-reported ROAS is
  lagging and incomplete. Monthly new-vs-returning audit.
- 7-day minimum judgment windows; low budget → longer.
