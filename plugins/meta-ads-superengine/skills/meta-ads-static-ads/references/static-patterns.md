# Static ad patterns — layouts, overlays, specs

Distilled from the vetted creative playbook (07.06.26) + canon corrections.
Design directions here must be executable by a non-designer in Canva.

## Specs (canon-locked)
- **Feed: 4:5 (1440×1800) default.** Landscape is dead for this use. 1:1
  for LinkedIn-style placements only if needed.
- **9:16 (Stories/Reels placements): safe zones top 14% / bottom 35% /
  sides 6%** — text there is covered by UI and was never seen.
- The old 20% text-overlay rule is retired; overlays are READ by the
  machine — write them like hooks (40-char front-load). "Dense text is now
  favored" is FALSE — meaningful and tight.

## Layout patterns
1. **Plain text-post repost** — a high-performing plain-text post look on
   stark white; native feel, zero design cost.
2. **Native UI mimic** — styled like a text conversation or social post
   ("Hey Coach, dropped 5 lbs this week still eating carbs!"). Real
   testimonials only, with consent.
3. **Ugly legal-pad / handwritten list** — a handwritten checklist,
   phone-shot in natural light ("My 3 non-negotiable morning habits…").
   Camera-roll authenticity beats stock.
4. **Before/after split-screen** — high-contrast pain state vs relief
   state, labeled. (Body-transformation imagery: mind compliance — check
   per-offer in the compliance gate.)
5. **One-page framework overlay** — the coach's method as a simple
   flowchart/blueprint image.
6. **Color-block testimonial** — real quote on a saturated solid.
7. **Long-copy static** — the cold-traffic engine for coaching: a designed
   OR plain text-heavy image that explains the offer. Run BOTH designed and
   plain styles — delivery personalizes format per user.

## Carousels (multiple signals in one ad unit)
- **How-to title & steps:** card 1 = bold title-slide hook → step cards →
  final card CTA.
- **Before/after progression:** card 1 before → card 2 after → remaining
  cards handle objections + method.
- Deep slide production → hand off to carousel-superengine when installed.

## Headline formulas on-image
- "[Pain]? [Short solution]" · "[Outcome] in [Timeframe]" (defensible
  timeframes only) · "[Lead magnet] + [real urgency]".

## When statics beat video
1. **Cheap angle testing** — 5–10 static concepts find the winning angle
   before an expensive video is scripted.
2. **Visual lead magnets** — a 1-page PDF mock + "Download" beats an
   over-explaining video.
3. **Margin math** — when production cost exceeds what the leads return.
