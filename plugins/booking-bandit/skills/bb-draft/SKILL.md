This skill is a placeholder in the v0.0.1 skeleton release. It has no drafting logic.

1. Tell the person, in one line, that Booking Bandit v0.0.1 is a skeleton release and the drafting engine has not shipped yet.
2. Point them at the plugin CHANGELOG for what is in this release and what is coming.

## What replaces this

A later release ships the real drafting flow: an agent carrying the reply rules and the DM knowledge base, reading the coach's own brand voice at draft time, with the drafts queued for the coach to review and send.
