# Body Structures — beat-by-beat reel skeletons

Niche-agnostic body skeletons, organized by the hook buckets the analysis detects
(`question`, `numbered/list`, `myth-bust/negation`, `contrarian/curiosity`,
`pain-callout`, `personal/story`, `statement`). Map an analysis result → matching bucket →
pick a skeleton, then fill the beats. The Hook beat comes from the `hook` skill (Step 3); the
CTA beat from `cta-scaffolds.md`.

Placeholders: `[pain]`, `[outcome]`, `[mechanism]`, `[timeframe]`, `[claim]`, `[proof]`,
`[number]`, `[item]`, `[stakes]`, `[turn]`, `[lesson]`.

> Rule of thumb: 1 idea per beat, keep total spoken length tight (~45–60s / ~700 chars for
> reach reels — story reels can run longer). Every skeleton ends on a CTA beat.

---

## question
**Skeleton A — answer-the-loop**
`Hook [question]` → `Stakes [why it matters / what's at risk]` → `Answer [the direct answer]`
→ `How [mechanism / steps]` → `CTA`

**Skeleton B — flip-the-assumption**
`Hook [question]` → `Wrong answer [what most assume]` → `Real answer [the truth]`
→ `Proof [example / result]` → `CTA`

## numbered/list
**Skeleton A — clean listicle**
`Hook [promise N items]` → `Item 1` → `Item 2` → `… Item N` → `Recap [tie items to outcome]`
→ `CTA`

**Skeleton B — countdown-to-payoff**
`Hook [N things, save the best]` → `Items 1…N-1 [quick]` → `#N [the strongest, slow down]`
→ `CTA`
*(Front-load one surprising item if the open is weak; the strongest still goes at #N.)*

## myth-bust/negation
**Skeleton A — correct-the-record**
`Hook [claim is wrong]` → `Secondary hook` → `Other side [what the other camp believes] [hold <main loop>]`
→ `Why it's wrong [the flaw]` → `What's true [the correction]`
→ `Proof [evidence / result]` → `CTA`

**Skeleton B — reassign-the-blame**
`Hook [you don't [pain] because of [scapegoat]]` → `Secondary hook`
→ `Other side [the scapegoat they blame] [hold <main loop>]` → `Real cause [[mechanism]]`
→ `What to do instead [fix]` → `CTA`

## contrarian/curiosity
**Skeleton A — open-the-secret**
`Hook [nobody talks about [subject]]` → `Secondary hook`
→ `Other side [what everyone does instead] [hold <main loop>]` → `Why it's hidden [reason it's ignored]`
→ `The reveal [the actual insight]` → `So-what [what it means for them]` → `CTA`

**Skeleton B — consensus-vs-me**
`Hook [everyone says [belief]]` → `Secondary hook`
→ `Other side [why they believe it] [hold <main loop>]` → `My take [the opposite]`
→ `Receipt [[proof]/[outcome]]` → `CTA`

## pain-callout
**Skeleton A — pain → relief (PAR)**
`Hook [name the pain]` → `Agitate [why it persists / cost of staying]`
→ `Reframe [the new way to see it]` → `Relief [the fix / first step]` → `CTA`

**Skeleton B — mirror-then-bridge**
`Hook [if you're [pain]…]` → `Mirror [you've tried X, Y, Z]` → `Bridge [what was missing = [mechanism]]`
→ `Proof [[outcome]]` → `CTA`

## personal/story
**Skeleton A — in-medias-res arc**
`Hook [drop into the moment / [timeframe] ago I was [pain]]` → `Turn [the thing that changed]`
→ `Lesson [the transferable takeaway]` → `CTA`

**Skeleton B — before / bridge / after**
`Hook [before-state]` → `Trigger [what forced the change]` → `Mechanism [what I did]`
→ `After [[outcome]]` → `Lesson` → `CTA`

## statement
**Skeleton A — claim → mechanism → proof**
`Hook [this is why you're [pain]]` → `Mechanism [the cause]` → `Fix [what to do]`
→ `Proof [[outcome]/[proof]]` → `CTA`

**Skeleton B — single-lever**
`Hook [[outcome] comes down to one thing]` → `Name the lever [[mechanism]]`
→ `How to pull it [steps]` → `CTA`

## By intent

The buckets above follow the hook. These three follow the reel's goal: use one when the goal
matters more than the hook's shape; the skeleton's `angle_kind:` stays the hook bucket of the
angle picked at Checkpoint 1. No fixed beat times; the `rehooks` rhythm is the only
timing rule. The secondary hook still follows the hook in each.

| Structure | Best for | Beats |
|---|---|---|
| **Transformation Arc** | Conversion | Shared-struggle hook → personal journey → breakthrough → how to apply it → CTA |
| **Myth-Buster** | Shares | Bold claim → Secondary hook → Other side [hold <main loop>] → why the common belief is wrong → proof → the better way → steps → CTA |
| **Authority Solution** | Trust, high-ticket offers | Problem → brief credibility → live demo or case study → 3 steps → results preview → CTA |

## Cross-cutting notes
- **Other side beat (myth-bust and contrarian):** one line, right after the secondary hook and
  before the turn, naming what the other camp believes or does. Its line comes from `polarize`
  at Step 2. It need not be fair: a straw man is fine, a made-up fact is not. Tag it
  `[hold <main loop>]` (an untagged extra beat can trip the flat-run check). It does not count
  against the beat budget.
- **Retention check:** if a body runs long, cut the beat with the least new information first
  (usually a second proof or a restated stake) — never the Hook or the CTA.
- **One promise, one payoff:** the body must deliver exactly the loop the Hook opened. A myth-bust
  hook that never states "what's true" feels like a bait — DISINTEREST in reverse.
- **CTA fit:** match the CTA goal to the body (a listicle/how-to → save-for-later; a story/result
  → comment-to-trigger). See `cta-scaffolds.md`.
