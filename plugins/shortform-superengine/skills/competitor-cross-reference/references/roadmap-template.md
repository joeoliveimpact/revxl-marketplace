# Competitor Cross-Reference — Strategy Roadmap Template

## Standing Rules (apply to every section)

1. **Evidence mandate:** every recommendation must cite a real account (handle), a metric, and where applicable a reel URL. No unsupported assertions.
2. **Why-it-matters · Est-impact · ROI×ease:** each finding carries all three. Use plain English: "impact: high," "priority: do now."
3. **Data-caveat header (required at top of every delivered roadmap):**
   > SocialCrawl does not expose Instagram saves or shares. Engagement throughout this document = views + likes + comments. Saves matter for educational content — treat engagement figures as a floor, not the full picture. Do not fabricate or estimate saves.
4. **Default diagnostic spine — reach efficiency vs engagement separation:**
   Before recommending anything, establish whether the client has a *reach problem* (the algorithm isn't distributing) or a *content problem* (audiences see them but don't engage). They are different diagnoses with different fixes. Reach efficiency = views ÷ followers. Compare to tier benchmarks (LARGE / MED / SMALL) from the competitor set.

## Section Structure

### 1. Executive Summary
State the one-sentence verdict (reach problem vs content problem, or both). Name the 2–3 highest-leverage fixes in plain English. Give the 90-day goal as a concrete metric shift (e.g., reach efficiency X% → Y%).

### 2. Current-State Assessment
A comparison table: client metrics vs field benchmarks by tier (LARGE / MED / SMALL). Required rows: followers, median views/reel, reach efficiency (views ÷ followers), median engagement rate, posting cadence. Interpretation: what the numbers mean, stated plainly.

### 3. Strengths Analysis
3–5 client strengths worth protecting or amplifying. Each entry: bold label · evidence (handle + metric) · why it matters · estimated impact · priority instruction (protect / amplify / build on).

### 4. Weaknesses Analysis
3–6 weaknesses ranked by impact. Each entry: bold label · evidence · why it matters · estimated impact · priority (#1 / #2 / etc.). Lead with the headline problem first.

### 5. Competitor Gap Analysis
5–8 specific moves competitors execute that the client does not. Each entry: bold label · evidence (handle + metric or reel URL) · opportunity statement · estimated impact. Source from the reel pull — cite real examples.

### 6. Opportunity Matrix (ROI × Ease)
Four buckets:
- **DO NOW** — high ROI, low effort (quick wins)
- **SCHEDULE** — high ROI, more effort (big bets)
- **TEST** — uncertain payoff, low cost
- **DEPRIORITIZE** — low ROI or high cost relative to gain

Map each gap/weakness finding to a bucket. Reference the section numbers (G1, W2, etc.) for traceability.

### 7. Recommended Content Strategy — Pillars
3–5 named content pillars, each with: pillar name · posting frequency · rationale (cites a gap or strength) · example hook or topic · why this is the highest-reach lane.

### 8. 30-Day Action Plan
Week-by-week breakdown. Each week: 2–4 specific actions with the "why" tied to a gap or opportunity code. End with a measurable day-30 target.

### 9. 90-Day Growth Roadmap
Three phases (days 1–30 / 31–60 / 61–90). Each phase: theme (e.g., "stop the bleed"), 2–4 actions, and a concrete reach-efficiency target for the phase end.

### 10. Key Hypotheses to Test
A table with columns: # · Hypothesis · How to test · Success signal. 6–10 rows. Each hypothesis should be falsifiable within 30–60 days.
