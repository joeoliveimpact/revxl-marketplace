# Naming — Agent Execution Reference

> Source: $100M Offers, Ch. 16 — "Enhancing the Offer: Naming"

## Core Principle

> "Like the tree that falls in the forest that no one hears, having a Grand Slam Offer will not make you money if no one finds out about it."

The name is the **first impression**. It determines:
- How well advertising converts
- Response rate on outbound (email, calls, texts)
- Engagement from organic content
- Whether the right avatar self-selects

> Same offer, different name → 2x, 3x, or 10x the response rate.

---

## The M.A.G.I.C. Naming Formula

```
M — Magnet (Magnetic Reason Why)
A — Avatar (Announce Your Avatar)
G — Goal (Give Them a Goal)
I — Interval (Indicate Time)
C — Container (Complete With a Container Word)
```

### Use 3-5 components. Not all are mandatory. Shorter and punchier wins.

---

### M — Make a Magnetic "Reason Why"

**Purpose**: Tells people WHY you're making this offer. Answers:
- "Why are they making this great offer?"
- "What's in it for me?"

**Examples**:
| Type | Words |
|---|---|
| **Price** | Free, 88% Off, Giveaway, $1 |
| **Seasonal** | Spring, Summer, Back to School, New Year |
| **Event** | Grand Opening, Anniversary, New Management |
| **Holiday** | Halloween, Valentine's, Black Friday |

---

### A — Announce Your Avatar

**Purpose**: Call out EXACTLY who this is for. Be as specific as possible.

**Specificity Rule**: Go sub-market, not city.
- ❌ "Baltimore" → ✅ "Towson, MD"
- ❌ "Business owners" → ✅ "Salon owners"
- ❌ "Moms" → ✅ "Rolling Hills Moms"

**Examples**: Bee Cave Dentists, Brooklyn Busy Executives, Brick & Mortar Businesses, Retired Athletes, Salon Owners

---

### G — Give Them a Goal

**Purpose**: Articulate the dream outcome. Can be a word, phrase, feeling, event, or measurable result.

**The more tangible and specific, the better.**

**Examples**: Pain Free, Celebrity Smile, 1st Place, Double Your Profit, First Client, High Ticket, 7 Figure, Little Black Dress, Never Out of Breath, Grand Slam Offer, Perfect Product

---

### I — Indicate a Time Interval

**Purpose**: Set expectations for how long results take.

**Compliance Note**: Don't pair quantifiable claims (income, weight loss) with a duration on ad platforms — it implies a guarantee. Use non-quantifiable goals instead.
- ❌ "$10,000 in 10 days" (claim + duration)
- ✅ "Make Your First Sale in 10 Days" (milestone, not claim)

**Examples**: 4 Hour, 21 Day, 6 Week, 3 Month, 42 Days, 60 Minutes, 12 Months

---

### C — Complete With a Container Word

**Purpose**: Signals this is a SYSTEM, not a commoditized service. Something bundled and unique.

**Examples**:
| Category | Words |
|---|---|
| **Action** | Challenge, Bootcamp, Sprint, Intensive, Attack, Assault, Launch |
| **System** | Blueprint, System, Program, Game Plan, Fast Track, Shortcut |
| **Experience** | Masterclass, Workshop, Summit, Getaway, Deep Dive, Meetup |
| **Transformation** | Transformation, Comeback, Rebirth, Reset, Makeover, Detox |
| **Growth** | Accelerator, Incubator, Catapult, Slingshot, Liftoff, Explosion |
| **Method** | Hack, Cheatcode, Solution, Formula |

## Naming Enhancement Techniques

### Rhyming
> "Good rhymes stick in people's minds."

**Examples**:
- Six-Pack Fast Track
- 5-Day Book Print Sprint
- Marriage Thrive Deep Dive
- 12-Week 2-Putt Shortcut
- Celebrity Butt Shortcut

Don't force it — it's a "nice to have."

### Alliteration
All (or most) words start with the same letter/sound.

**Examples**:
- Make Money Masterclass
- Change Your Life Challenge
- Big Booty Bootcamp
- Debt Detox
- Real Estate Reset
- Life Coach Liftoff

Easier than rhyming for most people. Also don't force it.

## Agent Execution: Name Generator Protocol

### Step 1: Generate Components
For the client's offer, fill in:
- **M** — 3 magnetic reason-why options
- **A** — 2 avatar descriptions (hyper-specific)
- **G** — 3 goal/outcome phrases
- **I** — 2 time intervals
- **C** — 3 container words

### Step 2: Mix & Match
Create 8-12 name combinations using 3-5 components each. Not all names need all 5 components.

### Step 3: Apply Enhancement
Check each name for opportunities to:
- Add rhyming
- Add alliteration
- Shorten/punch it up

### Step 4: Select Top 3
Score each name on:
- **Clarity**: Does the avatar instantly know this is for them? (1-10)
- **Desire**: Does it trigger wanting? (1-10)
- **Memorability**: Would they repeat this to a friend? (1-10)
- **Brevity**: Is it short enough for an ad headline? (1-10)

### Step 5: Test
Run top 2-3 names in advertising. Note the winner. Use as control to test against.

## Offer Fatigue & Variation Framework

When offers stop converting, change in THIS order (lightest first):

| Priority | What to Change | Operational Weight |
|---|---|---|
| 1 | **Creative** (images, videos in ads) | Very Light |
| 2 | **Body copy** (ad text) | Light |
| 3 | **Headline/Name** (the wrapper) | Light |
| 4 | **Duration** of offer | Medium |
| 5 | **Enhancer** (free/discount component) | Medium |
| 6 | **Monetization structure** (pricing, upsell sequence) | Heavy |

> **Hormozi Law**: "You are not changing the value stack. You are changing the way it looks to the marketplace."

### The Wrapper Refresh Example
Same massage center:
1. "Six-Week Stress Release Challenge" → 
2. "42-Day Relaxing Holidays Challenge" →
3. "New Year Reset: 6-Week Tension-Free Blueprint"

Core offer: identical. Wrapper: refreshed. Leads: flowing again.

---

## Pro Tips

- **Name sub-items and bonuses** using the MAGIC formula too — it auto-enhances perceived value
- **Multiple aces in the hole** — having 3-4 working names you can rotate is the ultimate power position
- **Local businesses** fatigue faster (smaller TAM) — need more frequent wrapper changes
- **Don't change the machine** until you've exhausted all wrapper variations
