# 01 ... Bio & Intro Section Optimization

> **Scope:** Facebook personal profile Bio/Intro field ... the 101-character text that appears in search results, profile previews, and hover cards.

---

## Character Limit & Display Rules

| Attribute | Value |
|---|---|
| **Hard character cap** | 101 characters (including spaces & emojis) |
| **Visibility** | Search results, friend-request previews, profile header |
| **Emoji support** | Yes ... moderately encouraged for visual pop and CTA arrows |

Every character, space, and emoji must earn its place. The bio is the single highest-ROI text element on a coach's profile.

---

## The Bio Formula

Structure every bio using this exact three-part framework:

```
Hook (Problem Solved) + Credibility/Method + CTA
```

**Prioritize transformation-focused language over generic job titles.** Prospects don't care that you are a "certified trainer" ... they care about the specific result you deliver.

---

## Transformation-Focused Hook Formulas

### The "From / To" Statement
Instantly communicates the exact transformation you provide.
- *"FROM feeling stuck and anxious TO feeling clear and confident"*

### Character-Optimized Examples for Fitness/Health Coaches

| # | Bio Example | Chars | Angle |
|---|---|---|---|
| 1 | `Online Fitness Coach │ Helped 500+ women lose 20lbs sustainably │ DM 'FIT' for free plan 🔥` | ~92 | Authority |
| 2 | `From exhausted to energized │ I help busy moms lose fat │ NASM Cert │ DM 'ENERGY' for guide 👇` | ~97 | From/To |
| 3 | `Helping busy pros get fit & pain-free │ 100+ clients │ Tap the link in bio for free assessment 🔗` | ~99 | Corporate |
| 4 | `Health Coach │ I take burnt-out executives from stuck to thriving │ DM 'READY' to start today!` | ~97 | Executive |
| 5 | `Fat Loss Coach │ Build muscle without restrictive diets │ DM 'PLAN' for your free routine 🚀` | ~93 | Anti-Diet |

## CTA Placement Rules

The CTA lands at the end of the bio (roughly the final quarter of the 101 characters) to drive immediate conversions.

### Recommended CTA Types

| CTA Type | Template | When to Use |
|---|---|---|
| **DM Drive** | `DM '[KEYWORD]' for [free asset] 👇` | Default ... tags leads and opens 1:1 conversation |
| **Link Click** | `Tap link in bio for [asset] 🔗` | When routing to your ONE direct link (the lead magnet, never a multi-link aggregator) |

---

## Algorithm Language: Suppressed vs. Amplified

The Meta algorithm scans your text and suppresses profiles using "salesy" language.

### 🚨 Suppressed (AVOID)
- "Click the link"
- "Message me now"
- "Like and share"
- "Tag a friend"

### 🔥 Amplified (USE)
- "DM me '[KEYWORD]'"
- "Tap the link in bio"
- "Comment your biggest [challenge]"

## Step-by-Step Bio Drafting Framework

Think in three proportional parts, not fixed character budgets. The ONLY hard cap is **101 characters total**. Aim for roughly: a Hook that takes the biggest share, a short Trust Signal, and a tight CTA. These proportions are a guide, not a rule... let the transformation and the CTA breathe and trim the trust signal first if you run long.

**Counting note:** every character counts against the 101 cap, including spaces, each emoji, and each separator (a "│" is 1 character, and coaches usually use two of them). Budget for those before you fill each part.

### Step 1 ... The Transformation Hook (largest share)
Define exactly who you help and the specific result.
- Template: `I help [Target Audience] achieve [Specific Result]`
- Template: `Taking you FROM [Pain] TO [Goal]`

### Step 2 ... The Trust Signal (short, and optional if space is tight)
Insert a rapid-fire credibility marker. If you have no provable credential yet, fold specificity into the hook instead of inventing proof.
- Examples: `500+ Clients`, `NASM Certified`, `Holistic Nutritionist`

### Step 3 ... The Algorithm-Compliant CTA (tight, always keep it)
Tell them exactly what to do next using algorithm-friendly language.
- Template: `DM '[KEYWORD]' for [Free Asset] 👇`
- Template: `Tap link in bio for [Asset] 🔗`

## Common Bio Mistakes

| Mistake | Why It Fails |
|---|---|
| No CTA in the bio | Misses 80% of first-impression conversions |
| Listing features over value | "Macros, Workouts, Check-ins" doesn't communicate transformation |
| Vague language | "We provide solutions" fails to stand out |
| Keyword stuffing | Cramming buzzwords looks cluttered and robotic |
| Never updating the bio | Stale bios with irrelevant lead magnets give a bad impression |
