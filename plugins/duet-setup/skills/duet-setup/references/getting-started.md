## The band picture

Think of the setup as a band. The person is the one who books the gigs. The main chat is the bandleader: it hears every request and hands each to the player who owns it. Each channel is one player with its own instrument: its own job, tools, Rules and notes. The tracker is the set list everyone can read. Claude Code, if linked, is a studio on the person's computer that takes jobs from the bandleader.

```text
                     You
                      |
              Main chat (bandleader)
        keeps the routing map and your rules
       /          |           |           \
  Channel 1   Channel 2   Channel 3   Channel 4
  one job     one job     one job     one job
  own Rules   own Rules   own Rules   own Rules
       \          |           |           /
          Tracker: the shared record of work

  Optional: Claude Code on your computer <-> main chat
```

Every player asks you before anything leaves the room.

## Glossary

- **Main chat (coordinator):** the Duet chat that routes work to the channels. You name it.
- **Channel:** a separate chat with its own Claude, set up for one kind of work.
- **Thread:** a side conversation inside a chat, for one task.
- **Instructions:** the short text a channel always reads first: who it is, its job, its hard rules.
- **Rules:** the longer list of how a channel works, saved in its memory from your own words.
- **Memory:** a short set of notes each chat reads at the start of a session. What each chat keeps: operating.md.
- **Routing map:** the one list of which channel owns which kind of work.
- **Routine:** a job a channel runs on a schedule.
- **Tracker:** an app like Linear that keeps the record of work outside the chat.
- **Connector:** an app's sign-in that lets Claude reach it. Looking after them: operating.md.
- **Proposed:** something Claude suggested that you haven't said yes to yet.
- **Claude Code:** Claude working on your computer, in the Code part of the Claude desktop app.
- **Master session:** the one Claude Code session that takes jobs from Duet.
- **Relay page:** a private page that holds the main chat's current address, so Claude Code can reply.

## What's normal

- A channel doesn't remember last week's conversation, only its memory and its tracker. That's why the tracker matters.
- A long chat gets summarised and starts to lose detail. Starting a fresh session is normal and cheap.
- Claude asks before sending, paying or deleting, even for small things. That's the setup working.
- A channel sometimes routes work to the wrong place in its first week. Each correction makes the routing map better.

## How to correct Claude

- **Say it where it happened.** Tell that channel, in plain words, what was wrong and what you want instead.
- **Make it stick.** If it should hold next time, add "Save this as a Rule." A channel only saves a Rule from your own words, so a note from the main chat won't change it.
- **Wrong channel?** Tell the main chat, which updates the routing map.
- **Same mistake twice?** Ask the main chat to look at that channel's instructions and Rules with you; the fix usually belongs in one of them.
- **Something sent or changed that shouldn't have been?** Say stop, then ask what happened. Claude will say what it did and what can be undone.
